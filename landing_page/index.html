How It Works

1️⃣

Install & Setup

Run the lightweight Windows installer. BatchForge sets up a secure, portable environment and SQLite database for your scripts instantly.

2️⃣

Browse or Write

Import existing `.bat` files, explore the 30+ built-in utility scripts, or write your own using our built-in syntax-highlighted editor.

3️⃣

Run & Schedule

Execute scripts safely in real-time or schedule them via Windows Task Scheduler to fully automate your daily workflows.

Why BatchForge?

Categorized Library

No more digging through folders. Group your scripts into beautifully organized categories with our built-in tree view.

Safe Execution

Run scripts asynchronously without freezing the UI. Our robust process-tree termination ensures you can safely halt any runaway script instantly.

Built-in Collection Browser

Comes pre-loaded with over 30 safe, highly practical batch scripts for Productivity, Security, and System Management. Preview and add them with one click.

Syntax Highlighting

A built-in editor featuring custom CMD/Batch syntax highlighting so you can easily review, write, and tweak your automations on the fly.

Scheduled Tasks

Seamlessly integrated with Windows Task Scheduler. Automate your daily backups or system cleanups directly from the UI.

Portable & Lightweight

Powered by Python and SQLite, packaged cleanly into a single Windows installer. Your library and settings travel with you.

The Story Behind BatchForge

Why I Built This

As a developer and sysadmin, I constantly found myself hunting down loose .bat and .cmd scripts scattered across my desktop, documents, and random folders. Running them felt risky, and managing them was a nightmare. I needed a centralized, safe, and organized hub.

I built BatchForge to solve this exact problem. It's more than just a library; it's a dedicated workspace where you can write, review, categorize, and safely execute automation tasks without the fear of a runaway script freezing your system. Every line of code was crafted with the goal of bringing modern UI/UX to classic Windows automation.
